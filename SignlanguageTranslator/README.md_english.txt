# 🧠 Sign Language Recognition System

## 📖 Project Overview
An intelligent system that uses a **camera** to recognize sign language gestures and convert them into written text,  
aiming to facilitate communication between individuals with hearing disabilities and the hearing community.

---

## 🧩 Project Concept
The system reads hand gestures through the camera, then analyzes them using a **Convolutional Neural Network (CNN)**  
to convert them into words or letters displayed on the screen in real time.

---

## 🛠️ Tools and Technologies Used
- **Python**
- **TensorFlow / Keras**
- **OpenCV**
- **Google Colab**
- **Flask**
- **HTML, CSS**
- **Visual Studio Code**

---

## ⚙️ How It Works
1. The camera captures hand gestures.  
2. The system processes the gestures using a deep learning (CNN) model.  
3. The translated text is displayed instantly on the user interface.

---

## 🎯 Project Objective
To promote inclusion and enhance interaction between individuals with hearing impairments and others  
by developing a system that provides **real-time translation** of sign language into text.
